# Media Action & Development Foundation (MADE-F)

Official Web Application for **Media Action & Development Foundation (MADE-F)** — [https://madefoundationng.org/](https://madefoundationng.org/)

## Tech Stack
- **Framework**: React + Vite + TypeScript
- **Styling**: Tailwind CSS + Lucide Icons
- **Backend / Database**: Supabase

## Local Development

```sh
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```
